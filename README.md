# LOSI ESCALA

Landing page premium do LOSI ESCALA.

## Direção visual
- Dourado + prata
- Branco quente com dourado quase imperceptível
- Modo escuro com dourado/prata
- Cards independentes com bordas douradas
- Ícones SVG próprios
- Responsividade mobile-first
- Transições e efeitos 3D discretos
- Scroll reveal exclusivo da página de apresentação

## Desenvolvimento

`npm install`
`npm run dev`
